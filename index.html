📋 خطوات الإعداد (مرة وحدة فقط):

  1. روح على supabase.com → سجّل مجاناً
  2. أنشئ مشروع جديد → احفظ الـ Password
  3. من Project Settings → API انسخ:
      • Project URL
      • anon public key
  4. من SQL Editor في Supabase نفّذ الكود هذا:
-- أنشئ جدول الإيرادات ``` CREATE TABLE incomes ( id TEXT PRIMARY KEY, city TEXT, amount_syp FLOAT8, amount_usd FLOAT8, description TEXT, date TEXT, exchange_rate FLOAT8, created_at TEXT ); – أنشئ جدول سلة المحذوفات CREATE TABLE trash ( id TEXT PRIMARY KEY, city TEXT, amount_syp FLOAT8, amount_usd FLOAT8, description TEXT, date TEXT, exchange_rate FLOAT8, created_at TEXT, deleted_at TEXT ); – فعّل الـ Real-time على الجدولين ALTER TABLE incomes REPLICA IDENTITY FULL; ALTER TABLE trash REPLICA IDENTITY FULL;

* من Database → Replication تأكد إن incomes و trash مفعّلين
